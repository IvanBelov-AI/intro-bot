# CLI Introduction Bot 🦾

A simple Python CLI (Command Line Interface) script that interacts with the user, collects data, and prints a formatted introduction using f-strings. This is my very first repository while studying AI Integration (Specialty 09.02.13).

## Tech Stack
* Python 3
* f-strings for text processing

## How to Run
1. Make sure you have Python installed.
2. Run the script in your terminal:
   ```bash
   python3 intro_bot.py
   ```
## Example

```text
What is your name? Ivan
What language are you learning? Python
What is your goal this year? Get a freelance client

Hello! My name is Ivan. I am learning Python to achieve my goal: Get a freelance client.
```
